## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-17 | Spoofing | anonymous use of the weather proxy | medium | mitigate | `@UseGuards(AuthGuard)`; e2e asserts 401 without a token (ASVS V2) |
| T-27-18 | Denial of service | one client exhausting the shared provider quota | high | mitigate | Per-client `weather` throttle 30/min, cache by station and hour shared by all members, in-flight de-duplication, concurrency cap 4, no provider call for a time older than 24 h |
| T-27-19 | Server-side request forgery | client influencing the outbound URL | high | mitigate | The query carries only validated numbers and an ISO time; host and path come from config only (`observationsUrl`); station ids come from the provider's own list, never from the client (ASVS V12/V13) |
| T-27-20 | Information disclosure | user location and time in logs | medium | mitigate | Logs carry the provider label and status only; spec asserts coordinates are absent |
| T-27-21 | Tampering / integrity | stale reading stored as the survey's weather | medium | mitigate | 90-minute tolerance on the reading's own time, 24 h window, out-of-range values dropped |
</threat_model>
