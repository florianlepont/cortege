# Phase 25.1 Plan 12: Parcel trend section Summary

The parcel trend card of "Historique de la parcelle" now prints in the PDF from the history cached on the phone: the summary line, the curve of totals cut between methods, and the ten per-factor changes, or a short note when there is nothing to show. All arithmetic is reused, none rewritten.

## What was built

- `buildTrendSvg(model, palette)`: one `svg` (`role="img"`, `aria-label` = `trend.curveA11y`, `viewBox` 515 x 128) from `buildTrend(model.drawn, TREND_PRINT_WIDTH)`: solid accent path per run (`trend-segment`), dashed `inkMuted` link across a method change (`trend-link`, dash "4 4"), a circle per point (current: radius 6, ink fill, accent ring; others: radius 4, accent), the total above (numeral font) and the year below (`?` when unknown) each point. Same sizes as `TrendCurve.tsx`, no animation.
- `buildTrendBlock(data, palette)`: entries from `buildEntriesFromOwn(data.history.items, data.surveyId)`, model from `buildParcelHistory`. Order of cases: no parcel id (`trend.noParcel`), history `null` (`trend.unavailable`), `model.isFirst` (`trend.first`), else the full card. Full card: heading, summary line (`titleStrong`/`titleAccent` or the new-method pair from `fr.parcelHistory.page.trend`), the `mixed` sentence when the curve spans two methods, the SVG, then the per-factor part (`card`: title `deltaHeading({ year })` or `deltaHeadingNoYear`, the screen's total line, ten rows `A 4 / 5 +1`; `differentMethod`: `trend.differentMethod`; `hidden`: nothing), and `trend.cachedAt({ date })` with `fetchedAt` as a French date (line omitted if the date is unreadable). Block id `trend`, height estimated in design units (about 350 for a full card, under 420 asserted).
- `trendSectionCss(palette)`: classes prefixed `trend-`, palette values only, flex two-column table, no `column-count`, no 1 px filled divs.
- 31 tests: curve (segments, links, one point, empty model, 8-point window, clamped totals, svgNumber-only numbers, no link/script), each note, summary wording (rise, fall, no change, new method), mixed sentence, factor table values, no-year heading, unfilled factors, method change, draft not in the history, cache-date omission, CSS rules.

## Deviations from Plan

**1. [Rule 1 - Bug] Path numbers rewritten through svgNumber.**
- **Found during:** Task 1
- **Issue:** `buildTrend` writes path coordinates with two decimals; the plan says all numbers pass through `svgNumber` (one decimal). Copying `segment.d` verbatim would break the T-25.1-13 mitigation and the rule.
- **Fix:** `pathData()` replaces every number of a path with `svgNumber(Number(n))`. The geometry module is untouched.
- **Files:** `mobile/src/app/survey-pdf/trend-section.ts`. **Commit:** b23adff6

**2. [Minor] No `xmlns` on the svg.** The factor chart (plan 10) keeps `xmlns="http://www.w3.org/2000/svg"`; here it is left out so the plan's "no http" check on the block is literal. Inline SVG renders without it (to confirm on the device check, as for every SVG of the sheet).
