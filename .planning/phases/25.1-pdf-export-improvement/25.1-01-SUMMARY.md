## Deviations from Plan

None in scope. Two small implementation notes:

- `no-var-requires` flags `const X = require(...)`, so the logo module id is held as a property (`LOGO_FILE.moduleId`), the same form as the font list and `tab-config.tsx`.
- In Jest the shared `image.mock.ts` makes `require("...ttf")` an ES-module-shaped object, not a number, so the test checks the read URI with `stringContaining` instead of an exact id. Metro gives a real numeric id in the app.
