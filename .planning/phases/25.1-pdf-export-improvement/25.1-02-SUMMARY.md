# Phase 25.1 Plan 02: Map projection and basemap snapshot Summary

Pure Web Mercator maths (512 px world, integer zoom 13 to 17) for the SVG parcel overlay, plus a basemap decision (offline pack, then online Plan IGN, else none) and an 8 s bounded MapLibre snapshot returned as a JPEG data URI.

## What was built

- `map-projection.ts`: `WORLD_SIZE_PX = 512`, `OFFLINE_ZOOM_RANGE` (13..17, test asserts equality with `OFFLINE_MIN_ZOOM`/`OFFLINE_MAX_ZOOM`; the file does not import `offline-packs`), `lngToWorldX`, `latToWorldY`, `worldYToLat`, `projectToFrame`, `metresPerPixel`, `boundsOfRings`, `fitFrameToBounds` (floored and clamped with a `zoomRange`, continuous with `null`), `chooseScaleBar` (10 m to 5 km steps, a quarter of the width), `ringsToPathD`, `parcelPolygonsFrom` (built on `buildParcelFeatureCollection`). Checked numbers of the research hold: 365 m by 330 m in 520 x 320 gives zoom 15 with all corners inside.
- `map-snapshot.ts`: `SNAPSHOT_TIMEOUT_MS = 8000`, `SNAPSHOT_JPEG_WIDTH_PX = 1100`, `SNAPSHOT_JPEG_QUALITY = 0.8`, `BasemapChoice`, `decideBasemap(center, deps)` (always the light `map` style file, never dark nor satellite; a throwing lookup counts as no area), `defaultBasemapDeps(isOnline)`, `takeBasemapJpeg({ mapStyle, frame, timeoutMs? }, deps?)` (`createImage` with `output: "file"`, `logo: false`, raced against the timeout, timer cleared in `finally`, PNG resized and saved as JPEG base64; every failure returns null and is logged under `surveyExport.snapshot`).
- `maplibre.mock.ts`: `StaticMapImageManager.createImage` jest.fn resolving a mock file URI. The existing `src/map` tests still pass.
- 35 new tests (19 projection, 16 snapshot), fake timers prove no timer is left after a timeout or a normal settle.

## Notes for the next plans

- `takeBasemapJpeg` returns `{ dataUri, frame }`; the SVG overlay must use that same `frame` (width and height are logical points, the JPEG is 1100 px wide but its aspect ratio matches, so lay the SVG with `viewBox="0 0 frame.width frame.height"` over an `<img>` of the same box).
- The caller passes an integer zoom frame from `fitFrameToBounds(..., { zoomRange: OFFLINE_ZOOM_RANGE })`; the outline-only fallback uses `zoomRange: null`.
- `decideBasemap` needs the centre first (geometry bbox centre), then `defaultBasemapDeps(isOnline)`; `isOnline` comes from the caller (non-hook `getNetworkStateAsync`).
- The 512 px world assumption and identical extents on iOS and Android are still to be confirmed by the device spike (25.1-07).
