# Phase 25.1 Plan 03: Catalogue, export contract and HTML helpers Summary

The three contracts every PDF builder shares are now fixed: the full French catalogue `fr.surveyExport` (dash-free, no gate exemption), the typed export data in `survey-pdf/types.ts`, and `survey-pdf/html.ts` with the single escape function and deterministic French number and date formatting.

## What was built

- `fr.surveyExport` keeps every key the current builder reads and adds the plan's keys; `identity.unknown` is "Non renseigné". Catalogue functions only interpolate: numbers appear only under `count` and `total` (plural ternaries), everything else is a preformatted string. `scaleLines.v3_2` and `v3_0` hold the ten factor lines A to J.
- The dash gate no longer has an exemption list; it asserts `survey-export.ts` is among the scanned catalogue files.
- `types.ts`: type-only imports (the draft summary types and `ParcelSurveyHistoryItem`), `SurveyExportData = Omit<SurveyExportInput, "apiUrl" | "accessToken" | "displayLocation"> & {...}`.
- `html.ts`: `escapeHtml` (five entities), `formatDecimal(value, maxDigits = 1)` (comma, trailing zeros dropped, no negative zero), `formatCoordinate` (5 digits, comma, zeros kept), `formatDateFr(iso, fallback)`, `svgNumber` (one decimal, dot).
- 42 new tests (catalogue plurals, interpolation, scale-line hygiene, ASCII file names, no dash; html helpers).

## Deviations from Plan

**1. [Rule 1 - Bug] v3.0 scale line of factor A**
- **Found during:** Task 1
- **Issue:** the plan's text "... = 0, 1, 2, 5" does not contain "= 5", which the plan's own behaviour list requires for every scale line.
- **Fix:** written per threshold ("Étage subalpin : 0 genre = 0 ; 1 genre = 1 ; 2 genres = 2 ; 3 genres et plus = 5. Autres étages : ..."), the same meaning as the existing hint.
- **Files:** `mobile/src/i18n/fr/survey-export.ts`. **Commit:** 2aa7018e

**2. [Rule 3 - Blocking] structure gate on font names**
- **Found during:** Task 3 verification (`src/__checks__/structure.test.ts`)
- **Issue:** `PDF_FONT_FAMILIES` string values under `title` and `label` keys were reported as user-facing literals outside `src/i18n`.
- **Fix:** the names are held in named constants and referenced by the object; the exported shape is unchanged.
- **Files:** `mobile/src/app/survey-pdf/types.ts`. **Commit:** 5b9f131d

**3. [Minor] `legacyGenusCount` singular** : added a "1 genre" branch next to the plural, with a test.
