## Deviations from Plan

**1. [Test design] Whole `factor_results` not comparable, submit response has no `factors`**
- **Found during:** Task 1, first run
- **Issue:** `factor_results` echoes each factor's input, so it differs by the arrays by design; the submit response body does not carry `factors`.
- **Fix:** the score comparison uses `score_points` per factor (and the stored `scores`); the submitted case asserts `factors` on the row, GET /v1/surveys/:id and the changes feed instead of the submit body. The server behaviour was correct from the first run (round-trip and replay tests passed).
- **Commit:** 7ad18540
