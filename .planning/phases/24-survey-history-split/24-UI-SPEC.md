# Phase 24 - UI Design Contract

> Visual and interaction contract for Phase 24 (Survey History Split). Generated by gsd-ui-researcher, to be verified by gsd-ui-checker.
> Every decision is locked upstream (24-CONTEXT D-01 to D-13, owner choices sketch 011 variant C and sketch 012 variant B+C, labels approved 2026-10-09). Where something was left open it is recorded under "Claude's Discretion" with a recommended default. No new colour, no new font, no new runtime dependency: the phase reuses the Phase 23 tokens and primitives and does not redefine them (see `23-UI-SPEC.md`).

## Spacing Scale

`brandSpacing4` (strict 4-grid). The legacy `brandSpacing` (6/10/22/28) is not used in new code.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4 | gap title to subline in a card, letter to bar |
| sm | 8 | gap curve to notice, gap between chips in a row status line |
| smd | 12 | gap title to curve, gap between the columns of a delta row, card header to rows. 12 is a deliberate member of the app's own `brandSpacing4` scale (xs 4, sm 8, smd 12, md 16, lg 24, ... xxl 48), not a stray value |
| md | 16 | page horizontal padding (`subContent`), card padding (trend card, delta card), row padding |
| lg | 24 | gap between the blocks of the page (trend card, delta card, list): `subContent.gap` |
| xxl | 48 | `subContent` bottom padding, extended by `useSubPageContentStyle` for the tab bar |

Exceptions (geometry, not layout padding): 2 (`xxs`, hairlines); delta bar height 8 and radius 4; curve geometry in the Curve section (padding 24 left and right, 32 top and bottom, radii 4, 6 and 7, stroke 2 and 3). The delta row height is 32 (on the grid, so not an exception). All rows that can be tapped keep `minHeight` 44 (`brandInteraction.hitTarget.min`): the summary row (48 by `AppGroupedList`), the history list rows (`SurveyRowFrame`, at least 44), the header "..." button (44 x 44). The delta rows are display only (no handler), so 32 is allowed.

## Typography

Four sizes (24, 16, 13, 12) and two weights (Regular 400, SemiBold 600) on every new element. All roles are existing tokens.

Inherited exception (not a new element, not counted in the four sizes and two weights): the value text of an `AppGroupedList` row is Sora-Medium 14 / 20 (`brandTypography.sectionBody`, `styles.value` in `ui/AppGroupedList.tsx`), shared by every grouped-list row in the app and by the two sibling rows of the summary ("v3.2 · cas 2", "10 sur 10"). The new history row reuses this existing value style unchanged and defines no typography of its own; the phase does not restyle the grouped list. The row LABEL is `brandTypography.input` (Sora-SemiBold 16), which is the Body role below.

| Role | Size / line | Weight | Font (token) | Used for |
|------|-------------|--------|--------------|----------|
| Heading | 24 / 28 | SemiBold 600, tracking -0.6 | `Sora-SemiBold` (`brandTypography.screenTitle`) | trend card title ("+13 points depuis 2023"), page title (`PageTitle`, drawn only off the native large title) |
| Body | 16 / 20 | SemiBold 600 | `Sora-SemiBold` (`brandTypography.input`) | delta card title ("Depuis 2025"), list row title (`SurveyRowFrame`), summary row label |
| Label | 13 / 18 | Regular 400 | `Jost-Regular` (`brandTypeScale.footnote` + `brandDefaultFontFamily`) | total line of the delta card, notices, list status line, page subtitle, "Journal du relevé" subtitle |
| Label strong | 13 / 18 | SemiBold 600 | `Sora-SemiBold` (`brandTypography.sectionHeader`) | list section header ("Relevés · 4"), delta text ("+2"), factor letter |
| Caption | 12 / 16 | SemiBold 600 | `Sora-SemiBold` (`brandTypography.ringValue`) for curve values; `Jost-SemiBold` (`brandTypography.meta`) for curve years | curve value labels, curve year labels (12 is the app floor; sizes under 12 are forbidden) |

Rules:
- SVG text (the curve labels) ignores Dynamic Type, as `GradientNumeral` does (Phase 23 precedent): the curve is hidden from the accessibility tree and replaced by one text label (Accessibility). Every other text uses `AppText`, so the caps apply (title 1.5, body 1.6, button 1.4).
- Delta text uses `maxFontSizeMultiplier={brandFontScaleCaps.button}` (1.4) so the 40 pt column never wraps; the letter column likewise. List rows and the summary row grow with Dynamic Type (two-line titles allowed, never ellipsis on the label of the summary row).
- Signs in French copy are ASCII "+" and "-" (same as `fr.parcelHistory` `signed`); no minus U+2212, no em dash.

Only through `useBrandTheme()` (`colors`, `semanticColors`, `onSurface`, `componentColors`, `visual`). No hex or `rgba(` literal in any new `.ts`/`.tsx` (ESLint rule, every file under `mobile/src` except the five token modules).

Not accent: row chevrons, the "..." glyph (`semanticColors.textStrong`), delta text for "=", the dashed link of a mixed curve (sage).

Why the curve is not band-coloured: terracotta and ochre on the forest gradient fail 3:1 (about 2.1:1 for terracotta on the mid stop), and a trend is a direction, not a band. Band tone is carried where it is contrast-safe: the `ScoreRing` of every list row (`totalTone`) and the factor bars of the delta card (`factorTone`). Colour is never the only signal: every delta has a sign or "=", every point has its value label, every ring has its number.

New contrast pairs the executor adds to the existing jest contrast tests (`src/app/visual-tokens.test.ts`, both schemes): `onSurface.success` and `onSurface.danger` on `visual.glass.cardFill` over canvas (at least 4.5:1); `visual.forest.sage` on the three forest stops (already in the Phase 23 table, at least 3:1 here).

## Derived values (pure helpers, unit tested, no rendering)

| Name | Rule |
|------|------|
| `method(item)` | `resolveMethodVersion(item.ibp_method_version)` (null = v3.0). An item without the field (older server) takes the method of its neighbour, so no mixed state is invented |
| `trailingRun(items)` | the maximal run at the end of the (up to 8) drawn items that shares the latest item's method |
| Trend delta | `run.length >= 2`: `last.total - run[0].total`; otherwise none |
| Trend title, delta > 0 | strong `+{n} point(s)` ("+1 point", "+13 points"), accent ` depuis {year}` |
| Trend title, delta < 0 | strong `-{n} point(s)`, accent as above |
| Trend title, delta = 0 | strong "Aucun changement", accent as above |
| Trend title, `run[0].year` null, or equal to the latest year | accent ` depuis le premier relevé` |
| Trend title, run of 1 after a method change | strong `Passage à la méthode v3.2` (the latest method), accent ` en {year}` (omitted if the year is null) |
| Row value (Surface 1 and 5) | table in Surface 1; the arrow value uses `run[0].total` and `last.total` of the trailing run over ALL submitted items (not only the drawn 8) |
| Delta card eligibility | current survey index `i >= 1` in the list and `method(items[i]) === method(items[i - 1])` |
| Delta "depuis" year | `items[i - 1].observation_year` |
| "First survey" | `items.length === 0` or (`items.length === 1` and that item is the current survey) |
