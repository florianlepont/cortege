## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-08 | Tampering | SQL injection through `q` or `author` | high | mitigate | Values only as bound `$n` parameters; LIKE wildcards escaped with `escapeLikePattern`; specs assert exact `values` arrays and that no template interpolates the text |
| T-25-09 | Information disclosure | member enumeration by name | medium | mitigate | Same exposure as `author_name` already in the community list; only display names of members with at least one finished public survey; caller excluded; capped at 5; no id, email, first/last name on the wire (D-17) |
| T-25-10 | Information disclosure | drafts or deleted surveys leaking through search | high | mitigate | `PUBLIC_SURVEY_PREDICATE` and `submitted_at IS NOT NULL` on both queries; e2e in plan 25-13 creates a draft and a deleted survey and asserts they never match |
| T-25-11 | Information disclosure | search text in logs | medium | mitigate | The service has no logger; the HTTP error filter strips query strings; spec asserts no logger call contains the text |
| T-25-12 | Denial of service | migration fails on a host without contrib | medium | mitigate | `postgres:16` official image ships contrib (A1); CI e2e re-migrates `ibp_test` before deploy; `translate()` fallback documented in the migration |
| T-25-SC | Tampering | package installs | low | accept | No package is installed |
