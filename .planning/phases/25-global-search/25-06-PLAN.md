## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> API | free place text, untrusted |
| API -> IGN (data.geopf.fr) | outbound HTTPS to a third party shared by every user from one VPS IP (50 req/s per IP) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-13 | Tampering | SSRF or parameter injection into the IGN URL | high | mitigate | Base URL only from config; the text is set with `URL.searchParams` as one encoded `q` value; no user-controlled host, path or extra parameter; spec asserts the single `q` value with `&` and `%` inside |
| T-25-14 | Denial of service | exhausting IGN's per-IP quota or our event loop | high | mitigate | 10 min LRU cache, in-flight de-duplication, 8 concurrent calls cap, 2.5 s timeout, per-user throttle on the endpoint (25-13); failures answer 503 quickly |
| T-25-15 | Information disclosure | typed addresses in logs | medium | mitigate | Warnings carry the label and the error message only; spec asserts no logger call contains the query; the HTTP filter already strips query strings |
| T-25-16 | Tampering | malformed or hostile provider payload | medium | mitigate | `mapGeocoderFeature` validates every field (strings, finite numbers), drops incomplete features, never forwards raw provider objects |
| T-25-17 | Spoofing | provider choice drifting to a paid or OSM host (D-09) | low | mitigate | Only the configured IGN URL exists in code; acceptance greps for no literal URL in the service |
| T-25-SC | Tampering | package installs | low | accept | `lru-cache` is already a dependency; no package is installed |
</threat_model>
