<objective>
Build the server side of the parcel group: the free-text parcel parser, an API Carto lookup by key on the cadastre provider (with a bbox helper and the shared HTTP rule), and `ParcelSearchService` (resolution, database fallback, survey count, cache).

Purpose: D-06 (parcels by cadastral number lead to Explorer on that parcel) and D-13 (accepted forms, API Carto, not the geocoder parcel index). The endpoint is wired in plan 25-13.
Output: `parcel-query.ts`, `cadastre-provider.service.ts` changes, `parcel-search.queries.ts`, `parcel-search.service.ts`, unit specs with recorded API Carto fixtures.

Design choice recorded (Claude's discretion within D-13): a 2-digit (or 2A/2B, 97x) department token before section and number does not reach IGN (no service resolves it) but narrows the database fallback to that department, so a studied parcel typed as "77 AB 0123" is still found and parcels of other departments are not shown.
</objective>
