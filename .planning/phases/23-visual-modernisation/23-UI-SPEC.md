# Phase 12.2 - UI Design Contract

> Visual and interaction contract for Phase 12.2 (Visual Modernisation). Generated by gsd-ui-researcher in AUTO mode, verified by gsd-ui-checker.

## Spacing Scale

The repo's strict 4-grid `brandSpacing4` is the scale. The legacy `brandSpacing` (6/10/22/28) is not used in new or restyled code.

| Token (`brandSpacing4`) | Value | Usage in this phase |
|-------------------------|-------|---------------------|
| xs | 4 | icon to label gap, tab dot to label, chip icon gap |
| sm | 8 | gap between chips, ring to text gap in compact rows, eyebrow tag to title |
| smd | 12 | list row vertical padding (compact), tile inner padding, gap between score tiles |
| md | 16 | screen horizontal padding, card padding, gap between blocks on one screen, row horizontal padding |
| lg | 24 | gap between sections, section header top margin, forest score card padding |
| xl | 32 | screen top spacing under a large title, empty-state vertical padding |
| xxl | 48 | empty-state illustration block, bottom scroll clearance above tab bar (added to `useTabBarClearance`) |

Density rules (D-05):
- Compact surfaces (Accueil, Compte, Paramètres): card padding 16, row padding 12 vertical by 16 horizontal, section header margin 24 top and 8 bottom, gap between blocks 16. Every interactive row keeps `minHeight` 44 (tokens `brandInteraction.hitTarget.min`); with a 24 icon and 12 padding a row is 48.
- Field surfaces (survey form A to J, parcel selection, wizard): spacing and every touch target unchanged. Only radii, block gaps (to the scale above) and typographic hierarchy may change. No control shrinks below its current size.
- Chips and segments keep `brandComponentTokens.choiceChip.minHeight` 44 as hit area even when the visible pill is smaller.

Exceptions (declared, all existing or geometry, none is layout padding):
- 2 (`brandSpacing4.xxs`): hairline offsets and the score-bar stub only.
- 6: gap between the ten factor bars (geometry of the chart, from sketch), and bar corner radius.
- Ring diameter 38, ring stroke 4, tab dot 4 x 4, glow bar height 6, tab bar height 64 (JS tree): geometry tokens in `visual-tokens.ts`, not spacing.
- Radii are not spacing: see Visual Contract, Radii.

## Typography

Four declared sizes and two text weights for every restyled surface. Roles resolve to `brandTypography` entries (file name equals PostScript name, `fonts.test.ts` guards it).

| Role | Size | Weight | Line height | Font file | Token |
|------|------|--------|-------------|-----------|-------|
| Body (rows, paragraphs, button labels, inputs) | 16 | Regular 400 (Jost) / SemiBold 600 (Sora, row titles and button labels) | 24 (1.5) for paragraphs, 22 for single-line row titles | `Jost-Regular`, `Sora-SemiBold` | existing `brandTypography.input`/`button` metrics, body default via `AppText` |
| Label / meta (secondary lines, section headers, eyebrows, chip text, tab labels on the JS bar) | 13 | Regular 400 (Jost) for secondary lines, SemiBold 600 (Sora for section headers, Jost for eyebrows) | 18 | `Jost-Regular`, `Sora-SemiBold`, `Jost-SemiBold` | `brandTypeScale.footnote` |
| Heading (screen title, forest card title, section card title) | 24 | SemiBold 600, `letterSpacing` -0.6 pt (not em) | 28 | `Sora-SemiBold` | NEW `brandTypography.screenTitle` |
| Display (score numeral only) | 68 | Light 300, `letterSpacing` -3.4 pt | 72 | `Sora-Light` | NEW `brandTypography.numeral` |

Exceptions:
- Caption 12 / 16 (existing floor of `brandTypeScale.caption`, never below 12): ring numeral inside the 38 pt ring (Sora-SemiBold), factor letters under the bars, JS tab bar label, uppercase eyebrow tag. Sketch sizes 10 and 11 are rejected.
- Weight 300 exists for the single score numeral (`Sora-Light`); no other text uses it.
- Legacy roles (`heroTitle` 34, `sectionTitle` 28 ExtraBold, `heroBody`/`sectionBody` Medium, `AppButton` Sora-Bold for non-glow variants) remain valid only in surfaces this phase does not restyle (auth, onboarding, field input chrome). A restyled screen title uses `screenTitle`, not `sectionTitle`/`heroTitle`.
- Heading line height is 28 for 24 pt (1.17), chosen on the 4-grid instead of 1.2 (28.8).
- SVG text (numeral) ignores Dynamic Type; the parent card carries the existing accessibility label and the SVG is hidden from the accessibility tree. All other text keeps `brandFontScaleCaps` (via `AppText`): title 1.5, body 1.8, label/meta 1.6, button 1.4.
- Forest card title, tag and body use the same roles (Heading or Body, Label); text on forest is white or the tints in the Color section, never sage on the halo core.
- "/50" next to the numeral: Jost-Regular 20 / 24 in sage, solid, aligned as a `TSpan` on the numeral baseline (documented size exception for the display unit).

### Depth and surfaces (D-04, D-12)

- Cards, chips, segments, rows, tiles: translucent fill plus hairline plus 1 pt inner top highlight (light `rgba(255, 255, 255, 0.5)`, dark `rgba(255, 255, 255, 0.05)`). No blur, no `elevation`, no drop shadow other than the optional soft light-mode `0 8px 24px rgba(30, 45, 25, 0.06)`.
- Real blur (`GlassSurface`: `BlurView` iOS below 26, `GlassView` iOS 26) only on floating controls: sheets, map buttons, map chips. Android: flat translucent fill, higher alpha (`visual.glass.androidFill`: light `rgba(247, 246, 240, 0.92)`, dark `rgba(24, 25, 28, 0.90)`).
- The only coloured shadow is on forest cards and the glow pill and glow bar.

### Signature: contour lines

- Two `Path` elements per card (sage group, moss group) from the deterministic `buildContourPaths()` (11 rings, 15 degree step, `viewBox="0 0 320 180"`, `preserveAspectRatio="xMidYMid slice"`).
- Wrapper `Animated.View` inset -12 inside the card's clipped inner view; clipped by the card radius.
- Used in: forest "Reprendre" card, survey score card, and as the placeholder, loading and offline background of map cards. NEVER over a live MapLibre map (D-13).
- At most two animated instances visible per screen.

### Score components

- Numeral: `GradientNumeral` (SVG text, `Sora-Light` 68, gradient white to `#C8DDA0`), with "/50" as a sage `TSpan`. Single constant switches to the solid fallback (RN `Text`, `Sora-Light`, `#C8DDA0`) if the device spike fails.
- Glow bar: height 6, radius 6, width proportional to score/50, below the numeral with 12 gap.
- Two glass tiles under the bar: "Peuplement et gestion" (value / 35) and "Contexte" (value / 15); fill `rgba(255, 255, 255, 0.09)`, border `rgba(255, 255, 255, 0.12)`, radius 16, padding 12; value Sora-SemiBold 16, label Jost 13.
- Ten factor bars (`FactorBarsChart`): one container, bars of equal flex width, gap 6, max bar height 64, height proportional to points/5 (0 points draws a 4 pt track stub), radius 6, vertical gradient from the tone lightened 20% to the tone, glow `0 0 12px` tone at 40% alpha; letter A to J under each bar (Sora-SemiBold 12, `textSecondary`). Bars are non-interactive (about 22 pt wide, below 44): no handlers, hidden from accessibility, one container label. Navigation to a factor stays on the 44 pt rows of `FactorsList` on the Score page (D-15).
- List score: `ScoreRing`, 38 diameter, stroke 4, round caps, rotation -90, arc by band tone, ratio score/50; inner numeral Sora-SemiBold 12; dashed track (`strokeDasharray="3 4"`, outline `visual.score.neutral`) with no inner text when there is no score. Drafts keep a completion ring in the neutral tone (A12). Replaces the rectangular `IbpScoreBadge` in lists (the badge stays where a tile is still shown).
- Form batch: `IbpTotalGauge`, `FactorProgressRing` get token colours and glow only, no size change.

## Interaction and Motion Contract

All motion goes through `brandMotion` and `ReduceMotion.System` (`.reduceMotion(ReduceMotion.System)` on entering/exiting builders, `reduceMotion: ReduceMotion.System` in `withTiming/withSpring/withRepeat`). Haptics only through `ui/feedback.ts`. No `LayoutAnimation`, no `useNativeDriver: false`. Animate transform, opacity and SVG props only, never `boxShadow`, gradients or layout in lists.

| Area | Element | Spec |
|------|---------|------|
| Score and gauges | glow bar | `withTiming` 0 to value, 500 ms (`durations.emphasis`), `easings.decelerate`, delay 120 ms; once per detail mount, not on return from a sub-page |
| | numeral | opacity 0 to 1 and `translateY` 8 to 0, `springs.snappy`; no counting (SVG text) |
| | sub-score tiles | optional count-up via `AnimatedNumber` (TextInput `animatedProps`), 500 ms |
| | list rings | 360 ms (`durations.slow`) decelerate, stagger 40 ms, rows 0 to 7 on first screen mount only; module-level Set of `surveyId:score` prevents replay on remount |
| | ten bars | `scaleY` from bottom (`transformOrigin: "bottom"`), `springs.gentle`, stagger 40 ms |
| Entrances | Accueil sections, Mes Relevés and Explorer rows | `FadeInDown`, 240 ms (`durations.base`), stagger 40 ms capped at 8 (`staggerMax`), first mount and `index < 8` only |
| | animated empty state | one-shot fade plus spring scale of the icon (`springs.snappy`), no loop |
| Screen transitions | list to detail, sub-pages, sheets | native-stack and native sheets as is (D-08); no shared element transitions |
| | tab change | JS tree `animation: "fade"`, `"none"` under `useReducedMotion()`; native bar unchanged |
| Press feedback | all pressables | existing `AppPressable` spring 0.97, opacity 0.9, skipped under reduced motion |
| | chips, segments | `feedback.selection()` on change |
| | glow pill | `feedback.impact.light()` on press |
| | submit and sync success | `feedback.notify.success()` plus halo pulse (ghost layer carrying the pill's static `boxShadow`, opacity 0 to 1 to 0 over 500 ms); failure `notify.error()` or `notify.warning()` |
| | status icons | check or sync icon scale-in, `springs.snappy` |
| Ambient | contour drift | 26 000 ms alternate loop (`withRepeat`, `Easing.inOut(Easing.ease)`): `translateX` -6 to 8, `translateY` 2 to -4, `scale` 1.04 to 1.1; gated by `useIsFocused()`, cancelled on blur; does not start under reduced motion and renders the "from" frame |

Reduced motion: shared values initialise at their final value when `useReducedMotion()` is true; rings, bars and numeral render complete, entrances jump to end, drift off. A `motion.test.ts` gate asserts the rules above across `src`.
