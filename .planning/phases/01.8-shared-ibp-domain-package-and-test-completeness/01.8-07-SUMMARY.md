# Phase 01.8 Plan 07: Mobile IBP adapter over the shared package Summary

The phone now scores, totals and checks submit readiness only through `@cortege/ibp-domain`. `mobile/src/app/ibp-scoring.ts` has shrunk from 352 lines of rules to an 88-line adapter with the same exported names. The shared parity, readiness and migration fixtures pass through that adapter. Submit readiness now names a missing IBP cas or an unsupported method version in French.

## What changed

**Adapter (`ibp-scoring.ts`).** It has no rule code, no allowed set and no factor-key list. It exposes:
- `computeRetainedScoresFromRawFactors(factors, context?: IbpSurveyContext)`, which calls `computeRetainedScores`.
- `computeIbpTotalsFromRetainedScores`, which calls `computeTotals`.
- `resolveFactorScoreFromRaw(key, raw, context?)`, which uses the package's retained score.
- `evaluateSubmitReadinessFromDraft(draft, now?)`, which returns the package readiness and adds `"parcel_ids"` when `resolveDraftParcelIds` is empty. `ready` takes that into account. The mobile `SubmitReadiness` type is the package type with the union extended.
- `resolveDraftParcelIds`, unchanged.
- `migrateDraftToV32`, re-exported for 01.8-10.

**Types (`types.ts`).**
- Re-exported from the package with `export type`: `FactorKey`, `FactorClass`, `FactorCanonical`, `FactorRetainedScore`, `IbpScores`, `RegionVersion` and `VegetationStage`.
- `SurveyDetailResponse` is now the package's `SurveyDetail`.
- `PublicMapItem` is now the package type.
- `PublicParcelStatusItem` is the package type with `geometry` narrowed to `GeoJsonGeometry`.

**Vegetation (`vegetation.ts`).** The region list, the stage lists, the defaults and `normalizeVegetationStageForRegion` now come from the package. Only the French labels stay local.

**Callers.**
- `useSurveyForm.ts` passes `{ region_version, vegetation_stage }`.
- `useLocalDraftSummary.ts` builds one context from the draft (`ibp_method_version`, `ibp_cas`, `ibp_cas3_scale`, `region_version`, `vegetation_stage`) and uses it for both the preview and the readiness check.
- `useSurveySyncSurveyOperations.ts` passes the three method fields at submit.
- The factor-key copies in `useLocalDraftSummary.ts` (its exported `FACTOR_ORDER` had no importer) and in `survey-screen-helpers.ts` now use `FACTOR_KEYS`.

**Readiness texts.**
- New catalogue entries in `fr.status.surveyOps.readiness`: `missingCas: "cas IBP non renseigné"` and `unsupportedMethod: "version de méthode IBP non prise en charge"`. Both are plain strings.
- `describeReadiness` has two new branches.
- The English debug message in `survey-sync/utils.ts` now names `missing ibp_cas` and `unsupported ibp_method_version`.
