# Phase 12.2 Plan 04: Signature primitives Summary

Forest card, contour lines, gradient numeral and glow bar of variant I, plus a navigator-safe focus hook, all driven by `theme.visual` tokens and covered by co-located tests including the reduced-motion paths. No dependency, token or font change.

## What was built

- **useScreenFocus**: reads `NavigationContext` with `useContext`; true with no navigator, otherwise follows `focus` and `blur` and unsubscribes both on unmount.
- **ContourLines**: two `Path` nodes from `CONTOUR_PATHS` (sage 1 pt at 0.55, moss 1.4 pt at 1) inside an inset -12 absolute layer, `pointerEvents="none"`, hidden from accessibility, viewBox `0 0 320 180` slice. The 26 s drift (`withRepeat` with `ReduceMotion.System`) runs only when `animated`, focused and Reduce Motion is off, and is cancelled otherwise and on cleanup. Header comment records the two-instance budget and the never-over-a-live-map rule (D-13).
- **ForestCard**: unclipped shell with the forest coloured shadow, clipped inner view with `experimental_backgroundImage` (resume or hero image), hairline, inset highlight and an always-set `fallback` background colour; radius 26 or 28; no `elevation` (test walks the whole tree); optional `ContourLines` with `animatedContours`.
- **GradientNumeral**: SVG `Text` with `url(#numeral-<id>)` fill (id from `useId()` sanitised to `[A-Za-z0-9_-]`), Sora-Light 68 from `brandTypography.numeral`, sage unit `TSpan`, Svg hidden from accessibility. `NUMERAL_RENDER_MODE` (`"gradient"`) is the single switch to the solid `#C8DDA0` `AppText` fallback. Null value renders nothing; the unit text is a prop (no literal text in the file).
- **GlowBar**: fill width is the clamped ratio as a percentage, `scaleX` animates from the left (`transformOrigin: "left"`) with `withDelay(120, withTiming(1, 500 ms decelerate))`; under Reduce Motion, or without `animate`, the scale starts at 1 and no timing runs.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] GlowBar track would have hidden its own glow**
- **Found during:** Task 3
- **Issue:** the plan lists `overflow: hidden` on the track, but a parent clip cuts off the fill's `boxShadow`, so the glow (the point of the component) would never show.
- **Fix:** the track does not clip; the fill is never wider than the track because it is a percentage width scaled by at most 1.
- **Files modified:** mobile/src/ui/GlowBar.tsx
- **Commit:** e83c985

**2. [Rule 3 - Blocking] `@react-navigation/native` is ESM and cannot load in Jest**
- **Found during:** Task 1
- **Issue:** importing `NavigationContext` in the tests failed to parse.
- **Fix:** `jest.mock("@react-navigation/native", ...)` with a plain `createContext`, as other navigation tests do. Production code imports the real package unchanged.
- **Files modified:** mobile/src/ui/useScreenFocus.test.tsx, mobile/src/ui/ContourLines.test.tsx
- **Commit:** 57e4cae
