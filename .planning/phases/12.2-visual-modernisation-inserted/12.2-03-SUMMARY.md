# Phase 12.2 Plan 03: Visual token layer Summary

Variant I token layer (`useBrandTheme().visual` in light and Graphite dark), new radii and typography roles, the embedded Sora Light font, a committed both-scheme contrast test, and a repaired ESLint colour rule with the six known literals tokenised.

## What was built

- **Tokens** (`visual-tokens.ts`, `theme-visual.ts`): values come from UI-SPEC, not the sketch. `buildTheme` is exported; `BrandTheme.visual` is resolved per scheme; Graphite dark neutrals in `theme.ts` are untouched (D-03).
- **Contrast** (`contrast.ts`, `visual-tokens.test.ts`): `contrastRatio`, `compositeOver`, `relativeLuminance`. The test covers every UI-SPEC pair in both schemes (forest title, accent, body, sage on the three stops; tag text on the composited fill; pill label; numeral end; glow end on the track; score tones and factor bars on the panel; textSecondary; active chip; active tab tint on the composited glass; accentText on panel and canvas). It also asserts D-14, D-16, no forbidden sketch colour (#8A9482, #62666D, #4C7A2A), gradient and boxShadow well-formedness, and the iOS glass fill equal to the pre-12.2 literals.
- **Font and roles**: `Sora-Light.ttf` (57964 bytes, sha256 `f5ba205911a8856328a36b7d1ac7ad0d94f5204fb5a72e3b39c2263d5dd9e357`) copied from `@expo-google-fonts/sora@0.4.2` fetched with `npm pack --ignore-scripts` in a temp directory (deleted), listed in `app.json`; `fonts.test.ts` passes. No package.json or lockfile change.
- **ESLint**: the hex and rgba selectors had been dropped by the second and third overrides (`no-restricted-syntax` is redefined, not merged). They are now repeated in all three overrides (`grep -c 'Literal\[value=/\^rgba'` prints 3) and the two new token files are excluded.
- **Probe**: a throwaway `src/ui/LintProbe.tsx` with a six-digit hex and an rgba string made `npx eslint` exit 1 with "Hex colors live in app/brand-tokens.ts, app/theme.ts, app/visual-tokens.ts or app/theme-visual.ts only (phase 4 DS-04, phase 12.2)" and the rgba equivalent; the probe was deleted and never committed. `npm run lint` exits 0 afterwards, so no further literal exists in any `.tsx`.
- **Tokenised literals**: `GlassSurface` (brandGlassFills), `AppActionSheet` and `FactorLetterStrip` (brandScrims), `GenusCameraView` (brandColors.black), `SurveyWizardScreen` (brandColors.white), `ParcelHistoryCard` close icon (theme.colors.textSecondary). iOS values unchanged.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Structure gate flagged colour literals under `title` and `label` keys**
- **Found during:** Task 2 (full mobile suite)
- **Issue:** `structure.test.ts` reads a string under a `label` or `title` object key as user-facing text, so `forest.title: "#FFFFFF"` and `pill.label: "#14210F"` in `theme-visual.ts` failed it.
- **Fix:** `title` uses `brandColors.white`; `label` uses a new `pillLabelColor` constant in `visual-tokens.ts`. Values unchanged.
- **Files modified:** mobile/src/app/theme-visual.ts, mobile/src/app/visual-tokens.ts
- **Commit:** 834d361

**2. [Rule 3 - Blocking] react-native test mocks lacked `Platform`**
- **Found during:** Task 3
- **Issue:** `GlassSurface` now reads `Platform.OS`; `ScoreLegend.test.tsx` and `PublicMapScreen.test.tsx` mock `react-native` without it, so 21 tests threw.
- **Fix:** added `Platform: { OS: "ios" }` to both mocks.
- **Files modified:** mobile/src/screens/public-map/ScoreLegend.test.tsx, mobile/src/screens/public-map/PublicMapScreen.test.tsx
- **Commit:** 1a0bc4f

**3. [Ordering] `brandScrims` landed in the Task 2 commit** (4cb901f) together with the other `brand-tokens.ts` edits instead of the Task 3 commit; the consumers are in 1a0bc4f. No behaviour impact.
