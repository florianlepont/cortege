# Phase 28 - UI Design Contract

> Visual and interaction contract for the map layers, the study mode and the curtain comparison of the Explorer. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 28-CONTEXT.md (decisions locked, including "Decided after research" and **"Owner decisions after the sketches 016 to 018 (2026-10-11)", which supersede the first version of this contract wherever they differ**), 28-RESEARCH.md, 25-UI-SPEC.md (format precedent), CLAUDE.md (Visual layer, Text and i18n), charter section 13, the in-repo UI code read on 2026-10-11 (`MapControls.tsx`, `ExplorerSheet.tsx`, `OfflineAreasSheet.tsx`, `DownloadStatusView.tsx`, `ScoreLegend.tsx`, `AppActionSheet.tsx`, `AppGroupedList.tsx`, `fr/offline-map.ts`, `fr/settings.ts`).
> The app is React Native (Expo). No shadcn, no Tailwind: the design system is the in-repo one (`useBrandTheme()`, `brand-tokens.ts`, `mobile/src/ui/*`). "pt" below means React Native points.
> Every choice inside a locked decision is taken here; the ones that deserve a look on the phone are tagged **[discretion, owner reviews on device]** and collected in "Open for owner".
> Revision of 2026-10-11: no basemap switch and no third capsule button (a labeled "Couches" pill at the top-left replaces them), a three-block panel with a "Comparer" button and a "Parcelles" three-state control, chip-only download progress (the sheet closes after "Télécharger"), side tags 30 pt from the handle.

## Scope of the contract

One screen (Explorer, `PublicMapScreen`), one sheet (`ExplorerSheet`, panels mutually exclusive), plus one row in Paramètres.

| Surface | What this contract defines |
|---------|----------------------------|
| Explorer top-left "Couches" pill (and the round exit control while comparing) | Entry to the layers panel (section 1) |
| Explorer top-right capsule | Download button only; the Plan/Satellite switch is removed (section 1) |
| Study panel in `ExplorerSheet` | Fonds, Comparer, Superpositions (Types de forêt, Parcelles), sources and licences, states (sections 2 and 6) |
| Curtain on the map | Handle, side tags, hidden markers, exit, over-zoom hint (sections 3 and 4) |
| Offline area sheet and the download chip | Weight estimate before download, the sheet closing, chip-only progress, partial and failed results (section 7) |
| Paramètres > Cartes | Policy row and its action sheet (section 8) |
| Map legend | Attribution line follows the layers shown (section 5) |

**Explore mode is the screen as it is today, minus the basemap switch.** With the default study state (base = the saved Plan or Satellite preference, no Types de forêt, Parcelles = Toutes, no comparison) the only visible differences are: the "Couches" pill at the top-left, the capsule holding the download button alone, and the locate button placed under that smaller capsule. The Plan/Satellite choice moved into the panel (owner decision 2026-10-11). Nothing else existing is hidden (success criterion 3). Regression contract, each item stays as is: download button and its panel, clusters and survey markers, score legend and count pill, offline indicator, cluster list sheet, parcel tap and history, cadastre lines and parcel polygons (Parcelles = Toutes is today's rendering), edge glow while the download panel is open.

Base keys: `BasemapKey = "map" | "satellite"` stays for the picker, the PDF and the saved preference. The study layers use `MapLayerKey = "map" | "satellite" | "etat-major" | "carte-1950" | "photos-1950"` for bases and `"types-foret"` for the overlay.

Study state is `{ base, overlay, parcels, compareWith }` with `parcels: "all" | "withIbp" | "none"`, held in `useStudyMode`. **Persistence:** choosing **Plan or Satellite** in the panel writes the saved basemap preference (`map_basemap`), exactly as the old switch did, so it survives a restart. The **old bases** (Carte d'état-major, Carte de 1950, Photos 1950), the overlay, Parcelles and the comparison are **session-only**: they reset on cold start, are kept while the app lives and while the user changes tab (tabs stay mounted). "Default" below means: base = the saved preference, overlay off, Parcelles = Toutes, no comparison.

## Spacing Scale

Declared values, all from `brandSpacing4` (4-grid):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4 | Gap between a row title and its meta line; gap glyph to text in tags |
| sm | 8 | Gap knob edge to side tag (the tag sits 30 pt from the line: 22 pt knob radius + 8); gap between two map pills; gap between the "Couches" pill and the round exit control; gap inside a slot chip; gap between the three Parcelles chips |
| smd | 12 | Panel gap between blocks (`createPanelStyles().card.gap`); tile to text in a row |
| md | 16 | Row horizontal padding |
| lg | 24 | Gap between the last block and the bottom of the scroll |
| xl | 32 | Not used |
| xxl | 48 | Slot chip height; "Comparer deux fonds" button height |
| 3xl (64) | not used | |

Fixed sizes:
- Capsule: one round button, 50 x 50 (inherited, `createControlStyles` without separators), holding the download glyph. It is not rendered when offline maps are disabled by the feature flag (no download button). The locate button's `top` offset (`MapBottomDock`) derives from the capsule height (or from the capsule's `top` when the capsule is absent), not from a copied number.
- "Couches" pill: `MAP_PILL_HEIGHT` 40, glyph 18 + word, horizontal padding 14, at the capsule's `top` and `MAP_EDGE` from the left. Round exit control: 40 x 40 circle (a `size` prop on `GlassIconButton` `map-circle`, default 50), 8 pt to the right of the pill, only while comparing. Both reach a 44 pt target with `MAP_CONTROL_HIT_SLOP`.
- Layer row: min height 56, vertical padding 8, leading tile 32 (radius `brandRadius.badgeSm` = 12, fill `visual.glass.iconTile`, glyph `visual.glass.iconTint` 18). Trailing control zone 44 x 44.
- Switch row (Types de forêt): min height 56; the native `Switch` sits in the 44 pt trailing zone.
- Parcelles control: one row title (tile 32 + title), then three equal `AppChoiceChip` choice pills, min height 44, gap 8, full panel width, then one helper line.
- "Comparer deux fonds" / "Arrêter la comparaison" button: height 48, full width, radius `brandRadius.field` (18), 1 pt hairline.
- Slot chip (comparison sides): height 48, two chips side by side, radius `brandRadius.field` (18), gap 8, plus a 44 x 44 swap button between them.
- Curtain handle: pan strip 44 pt wide over the full map height; drawn line 4 pt wide (2 pt core + a 1 pt edge on each side); knob 44 x 44 circle.
- Side tag: 32 pt high pill (non-interactive, so the 44 pt rule does not apply), horizontal padding 12, max width = visible width of its side minus 30 minus 14.
- Map pills (hint, notices, download chip): `MAP_PILL_HEIGHT` 40; the download chip is interactive only in its failed and partial states, then with `MAP_CONTROL_HIT_SLOP` so the target reaches 44.
- Entry dot (active state of the "Couches" pill): 8 pt, 6 pt from the pill's top-right corner.
- Legend image in the panel: full width of the panel, aspect 300:69 kept.
- Screen bottom padding of the panel scroll: 24.

Exceptions: 1 pt hairlines; the 50 pt capsule button (inherited); the 32 pt side tags (non-interactive); the 4 pt handle line (2 + 1 + 1); 14 pt (`MAP_EDGE`, the existing Explorer edge inset, also the map pill horizontal padding and the placement of the "Couches" pill: inherited, matches the validated Explorer controls); 12 pt (`smd`, an existing `brandSpacing4` step already used by the Explorer controls); 6 pt (offset of the entry dot from the pill's top-right corner, a decoration offset, not layout spacing). Every pressable target is at least 44 x 44.

## Color

All values come from the theme; light and dark follow the system only. Basemaps are not scheme aware (they stay light in dark mode) except the recoloured Plan, so every control over a map takes a dense surface.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | the map itself (raster basemap) | Not themed. Behind it, `brandMapTokens.darkBasemapBackground` (`#0E1512`) as ground in dark |
| Secondary (30%) | `theme.visual.mapControl.glass` (capsule, "Couches" pill, exit control, knob, tags, pills) and the Explorer sheet glass `theme.visual.sheet` (panel) | Every control and the panel. Panel content takes the glass ink (`withGlassInk`) like the other Explorer panels |
| Accent (10%) | `visual.accentText` in the sheet; `visual.tab.dot` (moss) for the one on-map dot | Reserved list below |
| Destructive | not used in this phase | No deletion here. The download "failed" glyph uses `onSurface.danger`, glyph only |

Accent reserved for (exhaustive):
1. The selected radio glyph (`radio-button-on-outline`) of a base row and of the chosen side's layer.
2. The active dot on the "Couches" pill (study state differs from the default, including Parcelles other than Toutes).
3. The "Revenir à l'Explorer" link and the "Réessayer" link.
4. The border of the active slot chip (2 pt) when comparing.
5. The leading tile glyphs of layer rows (`visual.glass.iconTint`, as every other tile of the app).

(The selected Parcelles chip uses the `AppChoiceChip` active style; chips are not accent, charter 13.4.)

Other colour rules:
- The curtain line is white: core `visual.curtain.line` (white), edges `visual.curtain.edge` (graphite at about 45% alpha). The two-tone line reads on cream paper, on grayscale photographs and on the dark plan. Same values in both schemes, still declared per scheme in `theme-visual.ts` (rule: no literal elsewhere). The knob and the side tags use `mapControl.glass`, ink `mapControl.icon` / `mapControl.text`.
- Offline and error lines: glyph `cloud-offline-outline` / `alert-circle-outline` (error in `onSurface.danger`), text in secondary colour. No red text, no tinted box (as Phase 25).
- **Parcels and cadastre on the map (Parcelles control).** Three states, the same on the left and the right map while comparing:

  | State | Cadastre lines (raster) | Parcel polygons (fill + outline) | Taps |
  |-------|-------------------------|----------------------------------|------|
  | Toutes (default) | Drawn from zoom 15, opacity 0.9 (0.7 on Carte d'état-major and Carte de 1950) | All the polygons the Explorer draws today, with today's tokens: score-band fill for a scored parcel, warm grey (`parcelUnscored`) for a parcel without a usable score, neutral for the others | As today |
  | Avec IBP | **Not drawn** | Only the parcels that have at least one IBP survey in the Explorer data (a `hasSurvey` feature property drives a layer filter): score-band fill for a scored one, warm grey for one without a usable total. Parcels without any survey are not drawn | On drawn polygons as today |
  | Aucune | **Not drawn** | **Not drawn** | Parcels are not tappable; markers and clusters still are |

  A parcel focus coming from the search (Phase 25, selected terracotta) is **always drawn**, whatever the state, so a search result never lands on an empty map.
- **Z-order** (bottom to top): base, Types de forêt (opacity 0.55), cadastre lines (Toutes only), parcel casing, parcel fill, parcel outline, markers (hidden while comparing). Green still means a high score only.
- **Parcels on the old bases (rule for the pale historical maps).** The three old bases (Carte d'état-major, Carte de 1950, Photos 1950) look washed out under today's fill and a white casing. On them, in both schemes (the old bases are light in dark mode too), the parcel **fill alpha is multiplied by `brandMapTokens.parcelFillOldBaseFactor` = 0.6** (a score-band fill drops from 0.55 to about 0.33, the neutral fills proportionally; outlines keep their width and colour). **[discretion, owner reviews on device: the factor is a single number to tune on the phone]**
  - Add `brandMapTokens.parcelCasing` (a light line, white at about 85% alpha) drawn under `parcels-outline` with width `strokeWidth + 2`, **only** on the three old bases and when Types de forêt is on. On the old bases its alpha takes the same 0.6 factor. Plan and Satellite without the overlay keep today's exact rendering, in light and dark.
- Dark mode of the rasters: Plan keeps `darkenPlanIgnStyle`. Satellite and Photos 1950 are not recoloured (as today's orthophoto). Carte d'état-major and Carte de 1950 are dimmed in dark with a static `raster-brightness-max` per scheme, **0.8 in dark, 1.0 in light**, as numbers in `theme-visual.ts` (not hex). The Types de forêt overlay is not dimmed. **[discretion, owner reviews on device]**
- No `borderWidth` on a gradient view; no `borderCurve`.

## Layout and component contract

### 1. Entry: the "Couches" pill (top-left) and the download capsule (top-right)

**The basemap switch is removed** (owner decision): the capsule keeps the download button only, and the panel replaces the switch. The top-right capsule (`MapTopControls`, Liquid Glass on iOS 26, `mapControl.glass`) is one round 50 pt button, `download-outline`, unchanged in label and behaviour (`fr.offlineMap.areas.openSheet`), rendered only when offline maps are enabled. The locate button sits under it (offset derived from the capsule height).

**"Couches" pill** (`testID="map-layers-pill"`):
- A labeled glass pill at the top-left: `GlassSurface` on `mapControl.glass`, 40 pt high, glyph `layers-outline` 18 in `mapControl.icon`, the word "Couches" in 12 SemiBold `mapControl.text`, padding 14, 1 pt `mapControl.hairline`, at the capsule's `top` and 14 from the left edge. `accessibilityRole="button"`, label "Couches : fonds de carte, comparaison et superpositions", hint "Ouvre le panneau des couches", `accessibilityState={{ expanded: panelOpen }}`. It is always rendered (also when offline maps are disabled: layers and comparison do not depend on offline).
- Active state: the 8 pt moss dot at the pill's top-right while the study state differs from the default: a base other than the saved preference, Types de forêt on, **Parcelles other than Toutes**, or a comparison. The a11y value then reads "réglages modifiés". The dot is a state cue only; the panel says everything.
- It opens the study panel in the shared `ExplorerSheet`. Opening it clears the other panels (cluster list, offline areas), as `closeSheet` already assumes.
- **During a comparison** the top-left shows two controls side by side: the "Couches" pill (reopens the panel) and, 8 pt to its right, the **round exit control** (40 pt glass circle, glyph `close-outline`, label "Quitter la comparaison", `testID="curtain-exit"`). No visible text on the exit control; it is announced by its label.
- There is no rule disabling anything while comparing: the capsule only holds the download button, and the download panel stays usable.

Header (`AppSectionHeader` as the offline panel): title "Couches", subtitle "Choisissez un fond de carte, comparez-en deux et ajoutez des superpositions.", trailing `GlassIconButton variant="close"` (44 pt). The sheet is 55% of the window high and scrolls; the panel body is a `ScrollView`, so it never needs a second detent.

Three blocks, top to bottom (`createPanelStyles().card`, gap 12):

**Layer row** (`testID="study-layer-{key}"`):
- Leading 32 pt tile with the layer glyph: Plan `map-outline`, Satellite `earth-outline`, Carte d'état-major `compass-outline`, Carte de 1950 `document-text-outline`, Photos aériennes `camera-outline`, Types de forêt `leaf-outline`.
- Title (16 SemiBold, up to 2 lines) and below it the vintage line (13 Regular, up to 3 lines) with `time-outline` 14 in secondary colour when it states a date range. The vintage line is the "date of last update" text the Licence Ouverte asks for.
- Trailing, for bases: `radio-button-on-outline` (accent) / `radio-button-off-outline` (secondary), 22 pt, in a 44 x 44 zone. While the newly chosen base style loads: a 16 pt `ActivityIndicator` replaces the radio on that row only.
- Whole row is one `AppPressable` (`disableScale`, `RipplePressable` wave is not used in the sheet), `accessibilityRole="radio"`, `accessibilityState={{ selected, disabled }}`, label "{name}. {vintage}". Haptic `feedback.selection()` on a change.
- Rows are separated by 1 pt `colors.divider`, flat on the sheet glass. First 8 rows enter with `PanelRowEntrance` once on mount (Reduce Motion: none).

**Block 1, Fonds de carte, comparison off:** tapping a base row sets `base` at once and closes nothing (the user sees the map change behind the half-height sheet). Tapping the already selected base does nothing. **Plan and Satellite write the saved basemap preference** (as the old switch did); the three old bases are session-only.

**Block 2, Comparer:** a full-width button (48 pt, hairline, glyph `git-compare-outline` 20 + "Comparer deux fonds" in 16 SemiBold, `testID="study-compare-start"`). Tapping it starts the curtain (section 3). **Once comparing it becomes the stop control**: same place, glyph `close-outline`, label "Arrêter la comparaison" (`testID="study-compare-stop"`), which does the same as the round exit control on the map. The sentence "Les relevés sont masqués pendant la comparaison." appears under it while comparing. It is a button, not a switch.
- Starting: side A (left) = the base shown now. Side B (right) = **Photos aériennes (1950-1965)**, or Satellite when A is already the photos, or the first available layer when offline. The target side starts as "right" (a side chosen at once, never an empty slot).
- The **slots strip** appears pinned under the panel header (outside the scroll), so a side can be chosen and a base tapped in block 1 without scrolling between them. **[discretion, owner reviews on device]** Two slot chips side by side, each with a 12 caption ("Côté gauche" / "Côté droit") over a 16 SemiBold name. Exactly one chip is the **target**: 2 pt accent border and `accessibilityState={{ selected: true }}`. Tapping a chip makes it the target; the helper line reads "Touchez un fond pour le placer côté gauche." (or "côté droit").
- Tapping a base row while comparing assigns it to the target side. The radio of a row is on when the layer is on **either** side, and a small caption "Gauche" / "Droite" (12 SemiBold, secondary) shows under the radio of the row that holds each side.
- If the tapped layer is already on the other side, the two sides **swap** (never an error, never two identical sides). Explicit control: the 44 pt `swap-horizontal-outline` button between the chips, label "Inverser les côtés".
- After an assignment the target switches to the other side, so two taps fill both sides without touching the chips.
- Stopping: the curtain leaves; the base left on screen is **side A**. The markers come back. The slots strip disappears.
- A pair that the spike finds too heavy for the phone (likely only Plan against a photograph on a mid-range Android) is disabled with the reason "Cette paire est trop lourde pour ce téléphone." Conditional on the spike result; no restriction otherwise.

**Block 3, Superpositions:**
- **Types de forêt:** a switch row (`testID="study-overlay-switch"`). The overlay applies to both sides (locked). Meta: vintage line + coverage ("Couvre la France métropolitaine.") + "S'applique aux deux côtés de la comparaison." shown only while comparing. When on, the official legend image of the layer (300 x 69, bundled as an app asset because it must show offline) is drawn full width under the row on a paper-coloured tile, `accessibilityLabel` "Légende des types de forêt : feuillus, conifères, forêts mélangées, peupleraies, landes et forêts ouvertes". **[discretion, owner reviews on device; the planner confirms the class list against the legend image when fetching the asset, and drops the image if it does not read on a phone]**
- **Parcelles:** one row with the tile `grid-outline`, the title "Parcelles" and, below, a three-state control made of three equal `AppChoiceChip` choice pills "Toutes" / "Avec IBP" / "Aucune" (`testID="study-parcels-all|ibp|none"`), exactly one active, default Toutes, no confirmation. It covers the app's parcel polygons **and** the cadastre lines at once; the rendering of each state is the table in the Color section. A 13 Regular helper line under the chips describes the chosen state:
  - Toutes: "Lignes du cadastre et toutes les parcelles."
  - Avec IBP: "Seulement les parcelles qui ont un relevé IBP. Pas de lignes du cadastre."
  - Aucune: "Ni lignes du cadastre ni parcelles. Les parcelles ne sont plus touchables."
  - Why custom: none; the control is three existing chips in a row (`accessibilityRole="radiogroup"` on the row, each chip `radio`). Haptic `feedback.selection()` on a change. The pending map change is immediate.

**Sources and licences:** one block at the end, 13 Regular. A line for each layer currently shown (the displayed base, or both bases, Types de forêt when on, and the cadastre only when Parcelles = Toutes) with its **source and last-update line**, then the common attribution once. The same lines feed the legend (section 5). Static texts are in the catalogue (below). Nothing here is interactive.

**"Revenir à l'Explorer":** a text link (13 SemiBold, accent, 44 pt target, centred) at the foot of the panel, visible only when the study state differs from the default. One tap resets `{ base = saved preference, overlay = off, parcels = all, compareWith = none }`, haptic `feedback.selection()`, and the panel stays open.

### 3. Curtain (comparison on the map)

Two synchronised maps (research); the visible result is one view cut by a vertical line. Layer A is on the left, layer B on the right (locked). Overlays (Types de forêt, Parcelles state) are on both sides. North-up and flat in comparison (`touchRotate`, `touchPitch` off on both maps); zoom and pan stay on the left map. The right map ignores touches (`pointerEvents="none"`).

**Handle** (`CurtainHandle`, `testID="curtain-handle"`):
- A vertical strip 44 pt wide, full map height, centred on x, over both maps and under the sheet, the capsule and the pills. It owns a `Gesture.Pan`; the rest of the map stays interactive. x is clamped to `[22, screenWidth - 22]` so the 44 pt target is never half off screen.
- The line is 4 pt (white core, graphite edges, section Color) from the top safe area to the bottom of the map area.

### 4. Over-zoom, coverage and map notices

**Over-zoom (locked: scaled tiles, never a blank map).** Every raster source declares `maxzoom`, so MapLibre scales the last tile. Bases and overlay stay on screen at any map zoom.
- Rule: a pill appears when any layer shown is scaled by 4 or more, i.e. when `mapZoom >= maxTileZoom + 1` (256-pt tiles are read one level above the map zoom). For a layer capped at tile zoom 15 (Carte d'état-major, Carte de 1950) this is from map zoom 16; for Types de forêt (16) from 17; for Photos 1950 the effective cap is 18 online and 17 offline (offline pack cap, locked), so from 19 online and 18 offline.
- The pill is a non-interactive `MapInfoPill` (glyph `information-circle-outline` 16, 12 SemiBold), in the notice column, text "Fond peu détaillé à cette échelle" (a base) or "Superposition peu détaillée à cette échelle" (the overlay). Both can be true; the base text wins. `accessibilityLiveRegion="polite"`, appears with a 160 ms fade, never blocks touches. It disappears when the zoom goes back under the threshold. In comparison it names no side; it is true for at least one.
- Nothing else changes: no zoom lock, no automatic jump to another layer.

**Outside coverage.** A layer outside its coverage answers 404 (transparent in a raster source), so the base ground shows. The catalogue holds each layer's coverage box; when the view centre leaves it for a shown layer, the same pill style shows "{name} ne couvre pas cette zone." with `alert-circle-outline`. Photos 1950-1965 and Carte de 1950 cover France and most of the overseas departments, Carte d'état-major and Types de forêt cover mainland France.

**Offline, layer shown but not downloaded here.** When connectivity is absent and a shown layer has no pack at the view centre: persistent pill "{name} n'est pas téléchargée pour cette zone." with `cloud-offline-outline`; the base stays selected (no silent switch). Several layers: one pill per layer, stacked 8 pt apart, at most two, then "Plusieurs couches ne sont pas téléchargées pour cette zone."

**Online load error.** Pill "Impossible d'afficher {name}." with a trailing "Réessayer" link (13 SemiBold, 44 pt target) and the panel notice above.

**Notice column.** All pills sit in one column, top-centre, starting at the capsule's `top` + 58 (capsule height 50 + 8), so they never overlap the top-left "Couches" pill and exit control row or the top-right capsule. Order from the top: transient hidden-markers pill, coverage / offline / error pills, over-zoom pill. The download chip is not in this column (it sits beside the capsule, section 7).

### 7. Offline: estimate, closing sheet, chip-only progress, result

**Before a download (inside the offline area sheet form).** The current line "N tuiles · ~X Mo" (`areas.estimate`) is replaced by a layer-aware estimate from the catalogue estimator (covering zoom +1 for 256 pt rasters, measured weights, never `AVERAGE_TILE_BYTES`). These lines **stay in the form**:
- Line 1 (13 Regular, like the current estimate line, `styles.meta`): "Environ 84 Mo" (rounded to a whole number from 10 Mo, one decimal with a comma below).
- Line 2 (13 Regular, secondary): "Fonds de carte : 53 Mo. Autres couches : 31 Mo." (policy "all"). With policy "Fonds de carte seulement": "Fonds de carte seulement, réglable dans Paramètres." replaces line 2.
- Line 3 (13 Regular, secondary, only with policy "all"): "Réglable dans Paramètres, Cartes."
- The existing size warning (`tooLarge`, `exceedsCap`) is unchanged and replaces line 1 as today. **There is no weight cap and no confirmation dialog** (locked); the estimate is the only guard. Tile counts are no longer shown anywhere.

**After "Télécharger la zone affichée" (owner decision, sketch 018 A): the sheet closes and only the chip shows progress.**
- The tap dismisses the keyboard, starts the download and closes the offline sheet at once (the sheet's edge glow ends with it). There is **no running view in the sheet**: no progress bar, no "Téléchargement : N %" line, no tile count, no "En cours : {couche}" line. `DownloadProgressBar`, the `running` states of `DownloadStatusView` and the `areas.running.*` strings are removed; `measureStatuses` now only measures the two remaining states (failed, partial).
- If the user opens the download panel again while a download runs, the form shows with the download button disabled ("Téléchargement…", the existing `areas.downloading`) and one meta line: "Un téléchargement est en cours. Son avancement s'affiche sur la carte."
- **Success criterion 5 of ROADMAP Phase 28 ("the Explorer sheet shows the percentage") is met by the chip, not by the sheet** (owner decision, 2026-10-11): the percentage shows on the Explorer map, next to the download button. The planner records the criterion that way.

**The chip** (`testID="download-chip"`): a glass pill (`mapControl.glass`, 40 pt, 12 SemiBold) **to the left of the capsule's download button**, vertically centred on it, 8 pt gap, visible from the tap on "Télécharger" until its outcome is cleared.
- **Running:** glyph `cloud-download-outline` 16 + "Téléchargement : 42 %", the byte-weighted percentage across the sequential layer packs, never decreasing (existing max-hold guard). Appears at 0 % with a 160 ms fade. **Tapping does nothing** while it runs (not a button: `accessibilityRole="progressbar"`, value 0 to 100, label "Téléchargement de la zone").
- **Done:** glyph `checkmark-circle-outline` + "Zone disponible hors connexion", visible 4 s, then it disappears by itself (live announcement; no sheet view for a plain success).
- **Failed** (a **base** pack failed): glyph `alert-circle-outline` (`onSurface.danger`, glyph only) + "Téléchargement échoué". Pressable (`button`, 44 pt target). **Tapping reopens the offline sheet on the failed view** ("Le téléchargement a échoué / Vérifiez votre connexion, puis réessayez. / Réessayer"). It stays until tapped and resolved, or until the next download.
- **Partial** (a base is saved, an extra layer failed or stalled): glyph `alert-circle-outline` + "Zone enregistrée, sauf certaines couches". Pressable. **Tapping reopens the sheet on the partial view**: title "Zone enregistrée, sauf certaines couches", message "Ces couches n'ont pas pu être téléchargées : {noms}. Les fonds de carte fonctionnent hors connexion.", button "Terminé" (clears the chip). The area is `ready`, never deleted for an extra layer; "Réessayer" is not offered (a new download of the area is).
- Accessibility: running announces "Téléchargement de la zone démarré." once, then every 25% step from the screen (the same `announceStep`) and the outcome ("Zone disponible hors connexion", or the failed / partial label) as a polite live message. No endless loop, no pulse: the percentage text is the only feedback.
- Other tabs: the download keeps running; the chip lives on the Explorer. If the user comes back, a running, failed or partial chip is still there (a done chip has already gone). The existing survey prompt (`OfflineMapPrompt`) keeps its own "Téléchargement · N %" line fed by the same weighted percentage. The `DownloadEdgeGlowHost` glow stays tied to the open offline panel as today (so it no longer runs during the download itself).

**The 2 km survey prompt** keeps its copy; its figure ("environ 2 km autour, N Mo") now comes from the same estimator and follows the policy. No new sentence in this phase.

## Accessibility Contract

- Targets: every pressable at least 44 x 44 (capsule button 50, rows 56, chips 44 to 48, swap button 44, handle strip 44 and knob 44, "Couches" pill and round exit control 40 with hit slop to 44, links 44). Side tags and the running chip are not interactive.
- Roles and labels: "Couches" pill `button` with `expanded` and an active value; base rows `radio` with `selected` and `disabled`; Types de forêt row with a native `Switch`; Parcelles chips in a `radiogroup`, each `radio` with `selected` and the catalogue labels; "Comparer deux fonds" / "Arrêter la comparaison" `button` with a hint; slot chips `button` with `selected` for the target; handle `adjustable` with value text and increment / decrement actions (the curtain is operable without a drag); round exit control `button` labeled "Quitter la comparaison" (it has no visible text); section headers `accessibilityRole="header"`; decorative glyphs, the legend swatches and the tags are hidden from accessibility (the handle's value carries the names); download chip `progressbar` while running, `button` when failed or partial.
- Announcements: comparison start (live, once), over-zoom pill, coverage / offline / error pills (`accessibilityLiveRegion="polite"` on Android, `announceForAccessibility` on iOS, once when they appear); download start, every 25% step and outcome from the screen (the sheet is closed, so there is only one source).
- Focus order in the panel: header, close, offline notice, pinned slots strip (while comparing), base rows, Comparer button, Types de forêt switch, legend, Parcelles chips, sources, "Revenir à l'Explorer". On the map the order is: "Couches" pill, round exit control (while comparing), capsule, locate button, handle, then the rest.
- Dynamic Type: rows grow (min heights only); on-map pills and tags truncate at the tail; the sheet scrolls. No clipped text at AX3 in the panel.
- Contrast: panel text on the sheet glass through the glass ink (already verified at 4.5:1 by `glass-density.test.ts` for light and dark); map pills and tags on `mapControl.glass` (verified by `visual-tokens.test.ts`); the curtain line has two tones so it reads on light paper, grayscale photographs and the dark plan (3:1 non-text to be added to the contrast tests for the line over the three reference backdrops); the entry dot against the pill glass at 3:1 in both schemes (added test); lightened parcel fills on the old bases keep their outline at 3:1 against each old base (added test, tune the factor against it). Colour is never the only carrier: disabled layers have a glyph and a sentence; the target side has a border and the caption; the selected base has a radio; the Parcelles state has a helper sentence.
- Reduced motion: curtain placed at 50% and removed at once, tags, pills and the chip appear without fade, `PanelRowEntrance` none. Handle drag is direct manipulation and stays.
