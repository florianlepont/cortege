# Phase 28 - UI Design Contract

> Visual and interaction contract for the map layers, the study mode and the curtain comparison of the Explorer. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Sources: 28-CONTEXT.md (decisions locked, including "Decided after research"), 28-RESEARCH.md, 25-UI-SPEC.md (format precedent), CLAUDE.md (Visual layer, Text and i18n), charter section 13, the in-repo UI code read on 2026-10-11 (`MapControls.tsx`, `ExplorerSheet.tsx`, `OfflineAreasSheet.tsx`, `DownloadStatusView.tsx`, `ScoreLegend.tsx`, `AppActionSheet.tsx`, `AppGroupedList.tsx`, `fr/offline-map.ts`, `fr/settings.ts`).
> The app is React Native (Expo). No shadcn, no Tailwind: the design system is the in-repo one (`useBrandTheme()`, `brand-tokens.ts`, `mobile/src/ui/*`). "pt" below means React Native points.
> The owner was not available for this contract. Every choice inside a locked decision is taken here; the ones that deserve a look on the phone are tagged **[discretion, owner reviews on device]** and collected in "Open for owner".

## Scope of the contract

One screen (Explorer, `PublicMapScreen`), one sheet (`ExplorerSheet`, panels mutually exclusive), plus one row in Paramètres.

| Surface | What this contract defines |
|---------|----------------------------|
| Explorer top-right capsule | Third button: entry to study mode (section 1) |
| Study panel in `ExplorerSheet` | Bases, overlay, comparison switch and sides, sources and licences, states (sections 2 and 6) |
| Curtain on the map | Handle, side tags, hidden markers, exit, over-zoom hint (sections 3 and 4) |
| Offline area sheet and closed-sheet chip | Weight estimate before download, percentage inside and outside the open sheet, partial result (section 7) |
| Paramètres > Cartes | Policy row and its action sheet (section 8) |
| Map legend | Attribution line follows the layers shown (section 5) |

**Explore mode is the screen as it is today.** With the default study state (base = the saved Plan or Satellite preference, no overlay, no comparison) the only visible differences are: the capsule has a third button, and the locate button under the capsule moves down by one button. Nothing existing is hidden (success criterion 3). Regression contract, each item stays as is: Plan/Satellite one-tap switch, download button and its panel, clusters and survey markers, score legend and count pill, offline indicator, cluster list sheet, parcel tap and history, edge glow while the download panel is open.

Base keys: `BasemapKey = "map" | "satellite"` stays for the picker, the PDF and the saved preference. The study layers use `MapLayerKey = "map" | "satellite" | "etat-major" | "carte-1950" | "photos-1950"` for bases and `"types-foret"` for the one overlay.

Study state is `{ base, overlay, compareWith }`, held in `useStudyMode`, **never persisted**: it resets on cold start. It is kept while the app lives and while the user changes tab (tabs stay mounted). The saved Plan/Satellite preference (`map_basemap`) is only written by the capsule toggle, as today. **[discretion, owner reviews on device]**

## Spacing Scale

Declared values, all from `brandSpacing4` (4-grid):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4 | Gap between a row title and its meta line; gap glyph to text in tags |
| sm | 8 | Gap knob edge to side tag (the tag sits 30 pt from the line: 22 pt knob radius + 8); gap between two map pills; gap inside a slot chip |
| smd | 12 | Panel gap between blocks (`createPanelStyles().card.gap`); tile to text in a row |
| md | 16 | Row horizontal padding; map pill horizontal padding stays 14 (`MAP_EDGE`, inherited) |
| lg | 24 | Gap between the last block and the bottom of the scroll |
| xl | 32 | Not used |
| xxl | 48 | Slot chip height |
| 3xl (64) | not used | |

Fixed sizes:
- Capsule button: 50 x 50 (inherited, `createControlStyles`), three buttons, hairline separators. The capsule is now 3 x 50 + 2 hairlines = about 152 pt high. The locate button's `top` offset (`MapBottomDock`) derives from the capsule height, not from a copied number.
- Layer row: min height 56, vertical padding 8, leading tile 32 (radius `brandRadius.badgeSm` = 12, fill `visual.glass.iconTile`, glyph `visual.glass.iconTint` 18). Trailing control zone 44 x 44.
- Switch row (Comparer, Types de forêt): min height 56; the native `Switch` sits in the 44 pt trailing zone.
- Slot chip (comparison sides): height 48, two chips side by side, radius `brandRadius.field` (18), gap 8, plus a 44 x 44 swap button between them.
- Curtain handle: pan strip 44 pt wide over the full map height; drawn line 4 pt wide (2 pt core + a 1 pt edge on each side); knob 44 x 44 circle.
- Side tag: 32 pt high pill (non-interactive, so the 44 pt rule does not apply), horizontal padding 12, max width = visible width of its side minus 30 minus 14.
- Map pills (exit, hint, download chip): `MAP_PILL_HEIGHT` 40, with `MAP_CONTROL_HIT_SLOP` so the target reaches 44.
- Entry dot (active state of the entry button): 8 pt, 6 pt from the glyph's top-right.
- Legend image in the panel: full width of the panel, aspect 300:69 kept.
- Screen bottom padding of the panel scroll: 24.

Exceptions: 1 pt hairlines; the 50 pt capsule buttons (inherited); the 32 pt side tags (non-interactive); the 4 pt handle line (2 + 1 + 1); 14 pt (`MAP_EDGE`, the existing Explorer edge inset, also the map pill horizontal padding and the exit-pill placement: inherited, matches the validated Explorer controls); 12 pt (`smd`, an existing `brandSpacing4` step already used by the Explorer controls); 6 pt (offset of the entry dot from the glyph top-right corner, a decoration offset, not layout spacing). Every pressable target is at least 44 x 44.

## Color

All values come from the theme; light and dark follow the system only. Basemaps are not scheme aware (they stay light in dark mode) except the recoloured Plan, so every control over a map takes a dense surface.

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | the map itself (raster basemap) | Not themed. Behind it, `brandMapTokens.darkBasemapBackground` (`#0E1512`) as ground in dark |
| Secondary (30%) | `theme.visual.mapControl.glass` (capsule, knob, tags, pills) and the Explorer sheet glass `theme.visual.sheet` (panel) | Every control and the panel. Panel content takes the glass ink (`withGlassInk`) like the other Explorer panels |
| Accent (10%) | `visual.accentText` in the sheet; `visual.tab.dot` (moss) for the one on-map dot | Reserved list below |
| Destructive | not used in this phase | No deletion here. The download "failed" glyph uses `onSurface.danger`, glyph only |

Accent reserved for (exhaustive):
1. The selected radio glyph (`radio-button-on-outline`) of a base row and of the chosen side's layer.
2. The active dot on the entry button (study state differs from the default).
3. The "Revenir à l'Explorer" link and the "Réessayer" link.
4. The border of the active slot chip (2 pt) when comparing.
5. The leading tile glyphs of layer rows (`visual.glass.iconTint`, as every other tile of the app).

Other colour rules:
- The curtain line is white: core `visual.curtain.line` (white), edges `visual.curtain.edge` (graphite at about 45% alpha). The two-tone line reads on cream paper, on grayscale photographs and on the dark plan. Same values in both schemes, still declared per scheme in `theme-visual.ts` (rule: no literal elsewhere). The knob and the side tags use `mapControl.glass`, ink `mapControl.icon` / `mapControl.text`.
- Offline and error lines: glyph `cloud-offline-outline` / `alert-circle-outline` (error in `onSurface.danger`), text in secondary colour. No red text, no tinted box (as Phase 25).
- Legibility of parcels on the new bases (judgement, to settle on a device; research Legibility section 1 to 4):
  - Add `brandMapTokens.parcelCasing` (a light line, white at about 85% alpha) drawn under `parcels-outline` with width `strokeWidth + 2`, **only** on the three new bases and when the Types de forêt overlay is on. Plan and Satellite without overlay keep today's exact rendering.
  - Cadastre raster opacity: 0.9 (today) on Plan, Satellite and Photos 1950; 0.7 on Carte d'état-major and Carte de 1950 (per-layer value in the catalogue).
  - Types de forêt overlay: `raster-opacity` 0.55, drawn under the cadastre and the parcels. Z-order: base, overlay, cadastre, parcel casing, parcel fill, parcel outline, markers (hidden while comparing).
  - Parcel score fills and outlines keep their tokens. Green still means a high score only.
- Dark mode of the rasters: Plan keeps `darkenPlanIgnStyle`. Satellite and Photos 1950 are not recoloured (as today's orthophoto). Carte d'état-major and Carte de 1950 are dimmed in dark with a static `raster-brightness-max` per scheme, **0.8 in dark, 1.0 in light**, as numbers in `theme-visual.ts` (not hex). The Types de forêt overlay is not dimmed. **[discretion, owner reviews on device]**
- No `borderWidth` on a gradient view; no `borderCurve`.

## Layout and component contract

### 1. Entry to study mode (Explorer capsule)

The capsule (`MapTopControls`, Liquid Glass on iOS 26, `mapControl.glass`) goes from two buttons to three, top to bottom: **basemap switch, layers (new), download**. The two map-display controls are grouped, the download action stays last.

- New button: `layers-outline` at `mapControlIconSize`, glyph colour `mapControl.icon`, 50 x 50, `testID="map-study-button"`, `accessibilityRole="button"`, `accessibilityLabel` "Mode étude : couches et comparaison", hint "Ouvre le panneau des couches de la carte", `accessibilityState={{ expanded: panelOpen }}`. It is always rendered (also when offline maps are disabled by the feature flag: the layers and the comparison do not depend on offline).
- Active state: the 8 pt moss dot appears at the glyph's top-right while the study state differs from the default (a base other than the saved preference, the overlay on, or a comparison). The a11y value then reads "couches modifiées". The dot is a state cue only; the panel says everything.
- It opens the study panel in the shared `ExplorerSheet`. Opening it clears the other panels (cluster list, offline areas), as `closeSheet` already assumes.
- The basemap switch keeps its single-tap behaviour and its label (`fr.offlineMap.basemap.a11y.switchTo`). Its target is "Satellite" when the displayed base is Plan, and "Plan" in every other case (so from an old base a tap returns to Plan and writes the preference as today). **While comparing it is disabled** (`accessibilityState={{ disabled: true }}`, glyph at 40% opacity): which side it would change is ambiguous, and the panel owns the sides.
- The download button is unchanged and stays enabled while comparing.

### 2. Study panel (inside `ExplorerSheet`)

Header (`AppSectionHeader` as the offline panel): title "Mode étude", subtitle "Changez de fond de carte, ajoutez une couche ou comparez deux fonds.", trailing `GlassIconButton variant="close"` (44 pt). The sheet is 55% of the window high and scrolls; the panel is a `ScrollView` body so it never needs a second detent.

Top to bottom (`createPanelStyles().card`, gap 12):

```
[ header: Mode étude                                         (x) ]
[ offline notice, only when offline ]
[ Comparer deux fonds                              (Switch) ]
[ when on:  [Côté gauche  Plan] [<->] [Côté droit  Photos 1950] ]
[ when on:  Touchez un fond pour le placer côté droit.          ]
Fonds de carte
 ( ) Plan                    meta
 ( ) Satellite               meta
 (o) Carte d'état-major (1820-1866)   meta, 2 lines
 ( ) Carte de 1950
 ( ) Photos aériennes (1950-1965)
Superposition
 [leaf] Types de forêt                              (Switch)
        meta; "S'applique aux deux côtés."
        [legend image, when on]
Sources et licences
 one short line per layer shown + the common attribution
[ Revenir à l'Explorer ]  (link, only when the study state differs)
```

**Layer row** (`testID="study-layer-{key}"`):
- Leading 32 pt tile with the layer glyph: Plan `map-outline`, Satellite `earth-outline`, Carte d'état-major `compass-outline`, Carte de 1950 `document-text-outline`, Photos aériennes `camera-outline`, Types de forêt `leaf-outline`.
- Title (16 SemiBold, up to 2 lines) and below it the vintage line (13 Regular, up to 3 lines) with `time-outline` 14 in secondary colour when it states a date range. The vintage line is the "date of last update" text the Licence Ouverte asks for.
- Trailing, for bases: `radio-button-on-outline` (accent) / `radio-button-off-outline` (secondary), 22 pt, in a 44 x 44 zone. While the newly chosen base style loads: a 16 pt `ActivityIndicator` replaces the radio on that row only.
- Whole row is one `AppPressable` (`disableScale`, `RipplePressable` wave is not used in the sheet), `accessibilityRole="radio"`, `accessibilityState={{ selected, disabled }}`, label "{name}. {vintage}". Haptic `feedback.selection()` on a change.
- Rows are separated by 1 pt `colors.divider`, flat on the sheet glass. First 8 rows enter with `PanelRowEntrance` once on mount (Reduce Motion: none).

**Single-view behaviour (comparison off):** tapping a base row sets `base` at once and closes nothing (the user sees the map change behind the half-height sheet). Tapping the already selected base does nothing. The Plan and Satellite rows are the same state the capsule switch drives.

**Comparison on (the sides):**
- Turning the switch on: the curtain enters (section 3). Side A (left) = the base shown now. Side B (right) = **Photos aériennes (1950-1965)**, or Satellite when A is already the photos, or the first available layer when offline. The target side starts as "right" (a side chosen at once, never an empty slot).
- Two slot chips side by side, each with a 12 caption ("Côté gauche" / "Côté droit") over a 16 SemiBold name. Exactly one chip is the **target**: it has the 2 pt accent border and `accessibilityState={{ selected: true }}`. Tapping a chip makes it the target; the helper line under the chips reads "Touchez un fond pour le placer côté gauche." (or "côté droit").
- Tapping a base row while comparing assigns it to the target side. The radio of a row is on when the layer is on **either** side, and a small caption "Gauche" / "Droite" (12 SemiBold, secondary) shows under the radio of the row that holds each side.
- If the tapped layer is already on the other side, the two sides **swap** (never an error, never two identical sides). Explicit control: the 44 pt `swap-horizontal-outline` button between the chips, label "Inverser les côtés".
- After an assignment the target switches to the other side, so two taps fill both sides without touching the chips.
- Turning the switch off: the curtain leaves; the base left on screen is **side A**. The markers come back.
- Nothing in the base list is removed in comparison. A pair that the spike finds too heavy for the phone (likely only Plan against a photograph on a mid-range Android) is disabled with the reason "Cette paire est trop lourde pour ce téléphone." Conditional on the spike result; no restriction otherwise.

**Overlay (Types de forêt):** a switch row. The overlay applies to both sides (locked). Meta: vintage line + coverage ("Couvre la France métropolitaine.") + the sentence "S'applique aux deux côtés de la comparaison." shown only while comparing. When on, the official legend image of the layer (300 x 69, bundled as an app asset because it must show offline) is drawn full width under the row on a paper-coloured tile, `accessibilityLabel` "Légende des types de forêt : feuillus, conifères, forêts mélangées, peupleraies, landes et forêts ouvertes". **[discretion, owner reviews on device; the planner confirms the class list against the legend image when fetching the asset, and drops the image if it does not read on a phone]**

**Sources and licences:** one block at the end, 13 Regular. A line for each layer currently shown (the displayed base, or both bases, the overlay when on, and the cadastre) with its **source and last-update line**, then the common attribution once. The same lines feed the legend (section 5). Static texts are in the catalogue (below). Nothing here is interactive.

**"Revenir à l'Explorer":** a text link (13 SemiBold, accent, 44 pt target, centred) at the foot of the panel, visible only when the study state differs from the default. One tap resets `{ base = saved preference, overlay = off, compareWith = none }`, haptic `feedback.selection()`, and the panel stays open.

**Panel states**

| State | Rendering |
|-------|-----------|
| Online, nothing downloaded or all downloaded | All rows enabled |
| Offline, the area at the view centre has packs | Notice at the top (`cloud-offline-outline`, 13 Regular): "Hors connexion : seules les couches téléchargées pour cette zone sont disponibles." Layers without a pack are **disabled**: tile and title at 55% opacity, radio replaced by `cloud-offline-outline` 20, meta replaced by "Indisponible hors connexion : zone non téléchargée." (title stays full contrast for reading, the 55% applies to the tile and glyphs only) |
| Offline, no area covers the view centre | Notice: "Aucune zone téléchargée ici : aucune couche n'est disponible hors connexion à cet endroit." All extra layers disabled as above; Plan and Satellite keep their rows (they may show part of the cache) |
| Online, view centre outside a layer's coverage | The row stays enabled; its meta ends with the coverage sentence ("Couvre la France métropolitaine."). On the map, the notice pill of section 4 appears when that layer is shown there |
| Layer failed to load (online) | Notice at the top with `alert-circle-outline`: "Impossible d'afficher {name}. Vérifiez votre connexion." with the link "Réessayer" (reloads the style) and the link "Revenir au plan" (selects Plan). Only the failing layer's state changes |
| Policy "Fonds de carte seulement" and offline | Same as "layer without a pack": the extra layers are disabled with the offline reason. A footnote under the list: "Les couches supplémentaires ne sont pas téléchargées avec votre réglage actuel." |

### 3. Curtain (comparison on the map)

Two synchronised maps (research); the visible result is one view cut by a vertical line. Layer A is on the left, layer B on the right (locked). Overlays are on both sides. North-up and flat in comparison (`touchRotate`, `touchPitch` off on both maps); zoom and pan stay on the left map. The right map ignores touches (`pointerEvents="none"`).

**Handle** (`CurtainHandle`, `testID="curtain-handle"`):
- A vertical strip 44 pt wide, full map height, centred on x, over both maps and under the sheet, the capsule and the pills. It owns a `Gesture.Pan`; the rest of the map stays interactive. x is clamped to `[22, screenWidth - 22]` so the 44 pt target is never half off screen.
- The line is 4 pt (white core, graphite edges, section Color) from the top safe area to the bottom of the map area.
- The knob is a 44 pt circle on `mapControl.glass` with the 1 pt `mapControl.hairline`, glyph `swap-horizontal-outline` 22 in `mapControl.icon`, centred on the line at **32% of the window height** from the top, which stays above an open sheet (the sheet covers the bottom 55%). **[discretion, owner reviews on device]**
- It follows the finger exactly: no spring, no snap, no inertia, no haptic while dragging. The position is kept in a Reanimated shared value; the clip of the right map follows it on the UI thread.
- Entering the comparison: the line travels from the right edge to 50% over 360 ms decelerate (`brandMotion.durations.slow`, `easings.decelerate`), so the user sees the cut open. Leaving: back to the right edge over 240 ms, then unmount. Reduce Motion: it is placed at 50% / removed at once.
- Accessibility: `accessibilityRole="adjustable"`, label "Séparation de la comparaison", hint "Faites glisser, ou balayez vers le haut ou le bas pour la déplacer", value `{ min: 0, max: 100, now: percent, text: "Plan à gauche, Photos 1950 à droite, séparation à 50 %" }`, actions `increment` / `decrement` move it by 10 points. At the start of a comparison the live region announces "Comparaison : {gauche} à gauche, {droite} à droite. Relevés masqués."

**Side tags** (labels of the two sides):
- Two non-interactive pills in `mapControl.glass`, 32 pt high, 12 SemiBold, **attached to the handle at the knob's height**: the left tag ends 30 pt before the line, the right tag starts 30 pt after it (22 pt knob radius + 8 pt gap; found on sketch 017: with 8 pt the tags slid under the 44 pt knob). They travel with the handle and always name what is next to them.
- Text is the layer's short name: "Plan", "Satellite", "État-major", "Carte 1950", "Photos 1950". Each tag's max width is the visible width of its side minus 30 minus 14; when that is under 72 pt the tag fades out (160 ms; at once under Reduce Motion) and the names stay available in the handle's a11y value and in the panel.
- A side whose layer is unavailable offline gets the glyph `cloud-offline-outline` 14 before its name.

**Hidden markers:** survey markers and clusters are not drawn while comparing (a `ViewAnnotation` belongs to one map and would show twice or be cut). Parcels (casing, fill, outline) and the cadastre are drawn on both maps. The count pill stays but reads the viewport count as today. Feedback: when the comparison starts, a transient 40 pt pill under the exit pill reads "Les relevés sont masqués pendant la comparaison." for 4 s (fade 160 ms), and the same sentence is the helper line of the panel. The legend (colours of markers and parcels) stays: parcels still use score colours.

**Exit:** a `map-pill` (`GlassIconButton variant="map-pill"`), top-left at the capsule's `top` and `MAP_EDGE` 14 from the left, glyph `close-outline`, label "Quitter la comparaison" (`testID="curtain-exit"`). It exists whether the panel is open or closed, so the user never needs the sheet to leave. It does the same as turning the switch off. Closing the panel (swipe down or its close button) **does not** end the comparison: the curtain stays, full screen, until this pill or the switch.

**Interaction with other panels:** opening the download panel keeps the curtain visible behind it (panels are exclusive, the comparison state is not). Selecting a parcel keeps the comparison. Tapping the entry button while the panel is closed reopens it on the comparison.

**Fallback if the spike is a no-go** (CONTEXT: to confirm with the owner then, the owner excluded a quick toggle): the panel keeps the same slots and the switch label becomes "Basculer entre deux fonds"; the map shows a `map-pill` "Inverser les fonds" (`swap-horizontal-outline`) that cross-fades between the two layers over 160 ms. No other screen of this contract changes. Not built unless the spike is a no-go and the owner agrees.

### 4. Over-zoom, coverage and map notices

**Over-zoom (locked: scaled tiles, never a blank map).** Every raster source declares `maxzoom`, so MapLibre scales the last tile. Bases and overlay stay on screen at any map zoom.
- Rule: a pill appears when any layer shown is scaled by 4 or more, i.e. when `mapZoom >= maxTileZoom + 1` (256-pt tiles are read one level above the map zoom). For a layer capped at tile zoom 15 (Carte d'état-major, Carte de 1950) this is from map zoom 16; for Types de forêt (16) from 17; for Photos 1950 the effective cap is 18 online and 17 offline (offline pack cap, locked), so from 19 online and 18 offline.
- The pill is a non-interactive `MapInfoPill` (glyph `information-circle-outline` 16, 12 SemiBold), placed top-centre under the exit pill row, text "Fond peu détaillé à cette échelle" (a base) or "Superposition peu détaillée à cette échelle" (the overlay). Both can be true; the base text wins. `accessibilityLiveRegion="polite"`, appears with a 160 ms fade, never blocks touches. It disappears when the zoom goes back under the threshold. In comparison it names no side; it is true for at least one.
- Nothing else changes: no zoom lock, no automatic jump to another layer.

**Outside coverage.** A layer outside its coverage answers 404 (transparent in a raster source), so the base ground shows. The catalogue holds each layer's coverage box; when the view centre leaves it for a shown layer, the same pill style shows "{name} ne couvre pas cette zone." with `alert-circle-outline`. Photos 1950-1965 and Carte de 1950 cover France and most of the overseas departments, Carte d'état-major and Types de forêt cover mainland France.

**Offline, layer shown but not downloaded here.** When connectivity is absent and a shown layer has no pack at the view centre: persistent pill "{name} n'est pas téléchargée pour cette zone." with `cloud-offline-outline`; the base stays selected (no silent switch). Several layers: one pill per layer, stacked 8 pt apart, at most two, then "Plusieurs couches ne sont pas téléchargées pour cette zone."

**Online load error.** Pill "Impossible d'afficher {name}." with a trailing "Réessayer" link (13 SemiBold, 44 pt target) and the panel notice above.

All pills sit in a column top-centre at `top + 8`, below the safe area, never over the capsule or the exit pill; the column order from the top is: transient hidden-markers pill, coverage / offline / error pills, over-zoom pill.

### 5. Legend and attribution

The legend's expanded panel (`MapLegend`) keeps its title, rows and attribution line. The attribution becomes dynamic:
- Default (Plan or Satellite, no overlay): the exact existing text, unchanged (`fr.publicMap.legend.attribution`).
- Any other layer shown (base A, base B, overlay): "Couches affichées : {noms}. © Institut national de l'information géographique et forestière (IGN), Géoplateforme, Licence Ouverte. Carte : MapLibre." Names in the left to right order, overlay last, separated by commas.

## Decisions taken in this contract (reasoning)

| # | Decision | Reason |
|---|----------|--------|
| U-01 | Entry is a third capsule button `layers-outline`, between the basemap switch and download | The capsule is where the owner already looks for map-display controls; discreet; no new tab or screen (success criterion 3) |
| U-02 | Study panel lives in the existing `ExplorerSheet`, panels exclusive | One sheet pattern for the whole Explorer; no second sheet to coordinate |
| U-03 | Study state is ephemeral and reset on cold start; "Revenir à l'Explorer" resets it explicitly | Explorer must stay the default (locked); no hidden persistent mode |
| U-04 | Basemap switch is disabled while comparing | A tap would otherwise change an unnamed side |
| U-05 | Sides are chosen by a target chip plus a tap on a layer, with automatic swap | Works with one hand, no drag and drop, no error state, no two identical sides |
| U-06 | Default B = Photos 1950-1965 (or Satellite) | The comparison purpose is reading the age of the forest; 1950 photographs against today is the strongest pair |
| U-07 | Side tags attach to the handle at the knob's height | Always adjacent to what they name, no collision with the top-right capsule, simple clamping |
| U-08 | Exit pill top-left, independent of the panel; closing the panel keeps the curtain | The curtain is used full screen; the sheet covers 55% of it |
| U-09 | Handle is a 4 pt two-tone line with a 44 pt glass knob at 32% of the height | Readable on paper, photographs and dark plan with literal-free tokens; the knob stays above an open sheet |
| U-10 | Markers and clusters hidden while comparing, with a transient sentence and a panel sentence | Research: a second marker set or a cut marker is worse; the user is told why |
| U-11 | Over-zoom hint from a 4x scale; no zoom lock; per-layer thresholds from the catalogue | Locked: scaled tiles accepted; the hint prevents reading blur as a bug |
| U-12 | Disabled (not hidden) offline rows with the reason | The user sees the layers exist and why they cannot be used; matches "layer unavailable offline" |
| U-13 | No silent switch when a shown layer becomes unavailable offline; a pill says so | Surprise changes while in the forest are worse than a notice |
| U-14 | Closed-sheet download indicator is a tappable text chip, not a ring | Percentage as text is readable at 12 pt and reopens the sheet; fits criterion 5 |
| U-15 | Partial success: base packs required, extra layers best effort, the area is saved with a notice | Research Pitfall 4: the default "all layers" must not delete an area for one failing extra layer |
| U-16 | Policy in Paramètres > Cartes as a nav row opening `AppActionSheet`, with the weight in the option labels and a new optional `message` | Native-first rule (13.10b); the owner asked for the weight to be shown; the row stays beside the existing "Cartes hors ligne" |
