Ce qui ne bouge pas

  • Les surfaces pleines (cartes, liste de facteurs, chiffres de Mes Relevés) restent opaques : elles se lisent mieux.
  • Pas de nouvel effet : on harmonise le verre existant (OA-68).

Règle unique

  • Titre natif : toujours masqué quand la page dessine le sien (le bug « Compte » deux fois, comme OA-109).
  • Un bouton d'en-tête = 44 pt, verre sans contour, 14 pt du bord.

Hors lot

  • Mode sombre.
  • La police (OA-05), traitée juste après.
