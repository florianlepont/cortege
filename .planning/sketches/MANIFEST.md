# Sketch Manifest

## Design Direction
Cortege's dark mode must look good, not only pass contrast: calm, precise, with the brand green
used sparingly for action. The owner points to Linear as the reference and rejects Komoot's look.

## Reference Points
- Linear (owner reference)
- Not Komoot (owner anti-reference)
