# Sketch 001: Dark palette

## Design Question
The owner finds the current dark mode readable but not pretty (OA-80). Which direction should the
dark palette take? Reference given by the owner: Linear. Anti-reference: Komoot.

## How to View
open .planning/sketches/001-dark-palette/index.html

## Variants
- **A: Graphite** — near-black as Linear, very thin borders, soft greys, one green accent
- **B: Forêt de nuit** — black tinted deep green, thin green borders, one bright green for action
- **C: Sous-bois chaud** — warm charcoal, cream text, sage green with an ochre touch

## What to Look For
The same four screens in each palette (Accueil, Mes Relevés, a factor screen, survey detail):
overall feel, card separation, how the accent draws the eye to the one action, tab bar glass.
The layouts also preview owner decisions from the audit (no date, 3 tabs, stats on Mes Relevés,
buttons above the tab bar, detail as a summary); they are not the subject of this sketch.
